# تجارة TJARA — دليل المعامل السورية

نسخة React عربية متجاوبة من موقع TJARA، بواجهة RTL وصفحات للرئيسية ودليل المعامل وتفاصيل المعامل والمحافظات الصناعية. صور القطاعات والمعامل مضمنة محلياً في المشروع، وبيانات الدليل موجودة في `src/data/catalog.json`.

## التشغيل والتجميع

يتطلب المشروع Node.js 22 وpnpm 11.25 أو إصداراً متوافقاً.

```bash
pnpm install
pnpm dev
```

```bash
pnpm typecheck
pnpm build
pnpm preview
```

ينتج أمر البناء الملفات الثابتة في `dist/` وينشئ `dist/404.html` لدعم المسارات الداخلية عند الاستضافة الساكنة.

## GitHub Pages

يدعم إعداد Vite مسار المستودع الفرعي باستخدام متغير `BASE_PATH`. قبل التجميع لموقع Pages من نوع `https://OWNER.github.io/REPOSITORY/` استخدم:

```bash
BASE_PATH=/REPOSITORY/ pnpm build
```

وعند الاستضافة على نطاق جذر يمكن استخدام `pnpm build` مباشرةً. يجب تفعيل GitHub Pages من إعدادات المستودع إذا أُريد نشر نسخة عامة؛ رفع الشيفرة إلى GitHub لا ينشر الموقع تلقائياً.
